# Бот записи в салон красоты

Telegram-бот на Python 3.9+ (aiogram 3 + SQLite).

## Возможности
- Запись: услуга → мастер → дата → свободное время → имя → телефон → подтверждение
- Показывает только свободное время с учётом длительности услуги; двойная запись на одно время невозможна
- «Мои записи» — просмотр и отмена своих записей
- Администратор получает уведомления о новых записях и отменах
- `/admin` — все записи на 7 дней вперёд, сгруппированные по дням, с возможностью отмены (клиенту приходит уведомление)
- `/settings` — настройки прямо в Telegram: приветствие, название, адрес, телефон, часы работы, выходные, услуги (название, длительность, цена) и мастера (кто какие услуги делает). Изменения применяются сразу, без перезапуска

Команды `/admin` и `/settings` доступны только администраторам.

### Администраторы
- **Главные** — указаны в `ADMIN_IDS` в файле `.env`. Их нельзя снять через бота.
- **Дополнительные** — главные админы добавляют и снимают их в `/settings` → «👑 Администраторы» (по Telegram ID или контакту). Без перезапуска бота.
- Новый админ должен сам открыть бота и нажать Start, иначе бот не сможет присылать ему уведомления.

## Запуск
1. Создайте бота у @BotFather и получите токен.
2. Узнайте свой Telegram ID (например, у @userinfobot).
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_IDS`.
4. Установите зависимости и запустите:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

## Настройка
Наполнение салона редактируется в боте командой `/settings`.
`config.py` задаёт только начальное наполнение — оно переносится в базу `salon.db` при первом запуске.
Время считается по часовому поясу сервера, на котором запущен бот.
