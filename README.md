# Бот записи в салон красоты

Telegram-бот на Python 3.9+ (aiogram 3 + SQLite).

## Возможности
- Запись: услуга → мастер → дата → свободное время → имя → телефон → подтверждение
- Показывает только свободное время с учётом длительности услуги; двойная запись на одно время невозможна
- «Мои записи» — просмотр и отмена своих записей
- Администратор получает уведомления о новых записях и отменах; команда `/admin` — расписание на сегодня и завтра с возможностью отмены (клиенту приходит уведомление)

## Запуск
1. Создайте бота у @BotFather и получите токен.
2. Узнайте свой Telegram ID (например, у @userinfobot).
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_IDS`.
4. Установите зависимости и запустите:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

## Настройка
Услуги, цены, мастера, часы работы и выходные — в `config.py`.
Время считается по часовому поясу сервера, на котором запущен бот.
